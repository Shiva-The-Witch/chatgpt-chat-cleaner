# Security Policy

## Reporting a vulnerability

Please do not publish access tokens, cookies, session identifiers, private conversation content, or other sensitive account information in a public GitHub issue.

For security-sensitive reports, contact:

**Shiva Dehghan**  
Email: [redwitch1294@gmail.com](mailto:redwitch1294@gmail.com)

Include the extension version, affected behavior, reproduction steps, and any relevant technical details that can be shared safely.

## Repository hygiene

The project must not include hard-coded access tokens, cookies, API keys, passwords, or private account data.

Changes that introduce new network requests should clearly document their purpose and privacy impact.
